# Tendon-Driven Hand：标准手的肌腱物理扩展

> 研究原型与实验记录。**已验证可计算、可反传；尚未证明能稳定提高真实 EMG→Pose 的预测精度。**

## 一句话概括

在 StandardHandModel（SHM）的标准手表示上，增加肌腱几何、Hill 型肌肉产力和关节力矩残差，探索对预测手部姿态的可微物理校正。

## 原有基础与本项目工作

| 范围 | 内容 |
| --- | --- |
| SHM 原有基础 | 25 个节点、23 个自由度、姿态重定向、FK、骨架/蒙皮。**这些不是本项目新发明。** |
| 肌骨映射 | 将来源手部肌骨模型映射到 SHM；8 块腕骨刚性归并到 `bone0`，不增加 SHM 自由度。 |
| 肌腱与肌肉 | 整理 39 条来源路径，其中 37 条作为当前自由度下的功能性肌肉—肌腱单元；PT/PQ 因缺少旋前/旋后自由度而不作为有效驱动。实现肌腱长度、力臂和 Hill 型肌力计算。 |
| 可微校正 | 比较连续姿态所需力矩与肌肉可产生的力矩，以残差和姿态保真项共同更新预测姿态，并检查梯度能否回传。 |
| 验证 | 完成几何/梯度检查、真实批次的计算与反传验收，以及人工加噪姿态的校正对照。结果与边界见 [验证记录](docs/VALIDATION.md)。 |

## 核心计算链路

```text
EMG → 姿态预测 → SHM 关节角 q
                         ├─ 连续 q → 所需关节力矩
                         └─ 肌腱几何 + 激活 + Hill 型肌力 → 肌肉关节力矩
                            两路力矩残差 + 姿态保真 → 校正后的 q
                                              ↓
                                      监督损失与梯度回传
```

肌腱长度与力臂满足 `R(q) = −∂l_MT(q)/∂q`；物理残差比较 `τ_muscle` 与 `τ_required`。肌肉激活是待估计的状态，不是已知真值，也不能直接把 16 通道 EMG 一一对应到 37 个肌肉单元。

## 客观结论

这项工作有意义：它把原本用于姿态表示和显示的标准手，延伸为可研究肌腱受力与物理校正的统一接口；梯度链路已通过数值检查。但“物理上更一致”**不等于**“姿态一定更准确”。目前人工噪声实验中，物理校正降低了输入误差和力矩残差，却不及普通平滑的姿态精度；真实 EMG→Pose 的稳定增益仍未验证。
